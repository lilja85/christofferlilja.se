Programmering

Programmering är något som jag tycker mycket om och därför sysslar mycket med på min fritid. Jag håller främst på med webbprogrammering i något av serverspråken PHP eller ASP och det är främst dessa två språk jag kommer skriva om här.

PHP

Världens mest populära skriptspråk 2007 som oftast används för att skapa dynamiska webbsidor. Jag kommer inte beskriva grunderna här utan istället gå in på lite mer avancerade praktiska saker som kan förenkla och berika din kod.

JavaScript

Nuförtiden hör man ofta talas om Webben 2.0 och dess möjligheter. Ofta menar man då sidor med mycket JavaScript som sköter utseende på webbsidor eller anrop till och från servrar (Ajax). Jag ska nu försöka beskriva grunderna i hur detta går till i denna artikel.
