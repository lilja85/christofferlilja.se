BESKRIVNING

Jag experimenterat mycket själv med olika lösningar och tekniker för att lära mig mer om webbdesign och webbprogrammering. Här under följer en lite längre beskrivning av de olika projekten i kronologisk ordning med den senaste sidan överst.

HI TECH

Under 2006 satt jag som ordförande för informationsutskottet i studerandesektionen HI TECH på Jönköpings Tekniska Högskola. Där hade jag bl.a. hand om e-postutskick, affischer och såklart deras hemsida. Designen på sidan har jag nästan inte rört utan de behövde ett internt system för att enklare kunna uppdatera webbsidan med nyheter, händelser och information om utskott och vilka personer som gjorde vad.

Layouten är uppbygd i XHTML och CSS med så kallade lager för att enkelt kunna ändras i framtiden. För att kunna spara information användes PHP tillsammans med en MySQL-databas.

Funktioner som jag utvecklat speciellt för denna webbsida:

  • Kontaktformulär (så att besökarna kan skicka e-postmeddelanden direkt till berörd person)
  • Nyhetsadministration
  • Kalenderadministration
  • Backup av databas
  • Kontoadministration (För att centralisera kontaktinformation som används i de andra funktionerna och för att kunna administrera inloggningsuppgifter till de som vill kuna logga in på administrationssidorna)
  • Postadministration (information om de olika poster man kunde ha i HI TECHs styrelse)
  • Utskottsadministration (information om de olika utskott som tillhör HI TECH)
  • Hjälp-dokumentation (för att enklare kunna sätta sig in i hur systemet är tänkt att skötas)

VERANDAN

En kompis pappa ville ha en webbsida för att på ett smidigt sätt kunna exponera sig mot nya kunder. Här har jag gjort designen och skapat sidan efter en mall som jag fick i ett Word-dokument av min kompis.

Layouten är uppbygd i XHTML och CSS med så kallade lager för att enkelt kunna ändras i framtiden. För att kunna visa bilder lite mer "flashigt" användes en JavaScript-applikation vid namn Lightbox 2. Även lite PHP användes för att kunna skicka e-postmeddelanden.

Funktioner som jag utvecklat speciellt för denna webbsida:

  • Kontaktformulär (så att besökarna kan skicka e-postmeddelanden direkt till berörd person)

TORSBY PAINTBALL HB

En kompis som driver ett paintballföretag ville ha en hemsida där han kan skriva om paintball och hur det går till. Om en besökare på sidan känner att han skulle vilja spela paintball så kan ha boka det via ett e-postformulär.

Tekniker som användes var XHTML tillsammans med CSS för att skapa en layout baserad på lager och lite PHP för att kunna skicka e-postmeddelanden.

Funktioner som jag utvecklat speciellt för denna webbsida:

  • Kontaktformulär (så att besökarna kan skicka e-postmeddelanden direkt till berörd person)

STUDIEBOK

En kompis som jag träffade på internet försökte skapa en bra reklamfinansierad hemsida där studenter gratis skulle kunna byta, sälja och köpa begagnad kurslitteratur. Efter att ha hjälpt honom lite grann bestämmde jag mig för att ta mig an hela projektet för att skapa en professinell sida.

Tekniker som användes är XHTML och CSS för att kunna skapa en lagerbaserad layout för att enklare kunna ändra sidan. För att kunna prata med en server och databas användes ASP tillsammans med databasen Access.

Funktioner som jag utvecklat speciellt för denna webbsida:

  • Kontoinloggning (för att varje person skall kunna hantera sina annonser enkelt så får varje person ett eget konto)
  • Kontosäkerhet (Kontroller så att inte vem som hellst kan ändra, ta bort och lägg till saker i andras namn)
  • Annonsadministration (För att kunna administrera annonser)
  • Automatisk kontoadministration (Efter att annonser luggit ett bra tag blir de icke sökbara och om inte personen som skapade dem aktiverar annonsen igen så tas den bort ur databasen)
  • Sidadministration (För att kunna hålla koll och administrera allas konton och annonser)
  • Sidstatistik (En publik del som visar hur många annonser det finns och en intern som är lite mer avancerad)
  • Annonssystem (Ett enkelt system för att kunna rotera 3 olika storlekar av annonser på sidan och kunna räkna antal klick)
  • Sökfunktion (För att enkelt kunna söka efter kurslitteratur)

JÖNKÖPINGS OK

På min fritid sysslar jag ibland med orientering. Efterhand som jag lärde mig mer om datorer och hemsidor fick jag mer och mer ansvar för deras hemsida. Till slut fick jag i uppgift att bygga en ny. Denna sida är resultatet av hur det blev.

Webbsidan är tänkt att sköta en stor del av informationsflödet i klubbn och det är därför viktigt att allt fungerar som det ska och att det är användarvänligt, annars kommer folk att ha svårt för att använda sidan.

Tekniker som användes är HTML och CSS för att kunna formatera stilen på alla sidor samtidigt. Då jag var rätt ny på webbdesign användes också Tabeller och Ramar för att enkelt kunna skapa layouten. En ny sida är planerad som använder sig utav lager och modernare teknik. För att kunna prata med en server och databas användes ASP tillsammans med databasen Access.

Funktioner som jag utvecklat speciellt för denna webbsida:

  • Kontoadministration (för att kunna hålla reda på kontaktuppgifter till klubbens alla medlemmar och för att kunna dela ut inloggningsuppgifter till dem som vill det)
  • Gruppadministration (För att kunna dela in medlemmarna i olika grupper efter vilken behörighet de skall ha på webbsidan)
  • Nyhetsadministration
  • Bildadministration (För att kunna publicera bilder från diverse händelser)
  • Höndelseadministration (För att kunna administrera en dagligen uppdaterad kalender på hemsidan)
  • Anmälningsadministration (Medlemmarna kan anmäla sig till interna tävlingar via hemsidan)
  • Forum (Ett enkelt men skyddat forum för att kunna diskutera allt möjligt)
  • Arrangemangsadministration (För at kunna ge information om diverse olika arrangemang som klubben anordnar. Exempel på information är start- och resultatlistor som laddas upp via ett formulär)
  • Kommitteadministration (För att kunna administrera de olika kommittéer som finns i klubben)
  • Befattningsadministration (För att kunna skapa olika befattningar som man kan sitta på i kommittéerna)
  • Klubblänkadministration (För att enkelt kunna administrera länkar som pekar på andra klubbar)
  • Kommentarer (För att kunna skriva kommentarer till nyheter och sen kan en administratör redigera eller ta bort dem om det behövs)
  • Versionslogg (Då vi är flera ansvariga är det ibland bra att kunna se vem som har gjort vad på hemsidan)
